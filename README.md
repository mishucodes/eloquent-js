# Eloquent JavaScript: Exercises & Projects
 
My notes, exercise solutions and projects from all 21 chapters of *Eloquent JavaScript* (3rd edition) by Marijn Haverbeke. I worked through the book from September 2025 to January 2026.
 
## Projects
 
| Chapter | Project | What I built |
| --- | --- | --- |
| 7 | [Robot](Chapter%2007%20-%20Project%20%28Robot%29) | A mail-delivery robot in a village graph, from a random robot to a smarter route-finding one |
| 12 | [A Programming Language](Chapter%2012%20-%20Project%20%28A%20Programming%20Language%29) | My own toy language with a lexer, parser and translator. It later became **[Teddy](https://github.com/mishucodes/teddy)**, now with a [live playground](https://try-teddy.vercel.app) |
| 16 | [Platform Game](Chapter%2016%20-%20Project%20%28Platform%20Game%29) | A browser platform game, with dark and responsive styles |
| 18 | [Conway's Game of Life](Chapter%2018%20-%20HTTP%20%26%20Forms/Exercises/Conway's%20Game%20of%20Life) | The Game of Life, sized to fit the visitor's screen |
| 19 | [Pixel Art Editor](Chapter%2019%20-%20Project%20%28Pixel%20Art%20Editor%29) | A pixel art editor in the browser |
| 21 | [Skill-Sharing Website](Chapter%2021%20-%20Project%20%28Skill%20Sharing%20Website%29) | Notes on WebSockets, long polling and building servers in Node.js |

## Running the browser projects
 
Open the project's `index.html` in a browser. The JavaScript-only files can be run with Node.js: `node "<file>.js"`.
